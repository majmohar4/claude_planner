# launch-checklist.md — tick at release (from dev.to/shayy checklist + project additions)
1. Analytics — key events tracked before launch (signup, activation).
2. Feedback board in-app.
3. Error monitoring — frontend + backend, stack traces, affected users.
4. Transactional emails — welcome, password reset, notifications.
5. Landing page — headline, real screenshot, CTA.
6. Critical-path tests — fresh signup, core flow, reset, logout/login, 2–3 external testers.
7. Launch channels prepared.
8. User communication channel.
9. Ship before perfect.
Additions: startup logo + loading animation; privacy policy + ToS; offline/server-down UX verified; backup/export verified.
